# Smart Task Management System

## Features
- User Authentication
- CRUD Task Management
- PostgreSQL Integration
- REST APIs
- Real-time Notifications using WebSockets
- Analytics using Pandas & NumPy

## Technologies Used
- Python
- Flask
- PostgreSQL
- Flask-SocketIO
- Pandas
- NumPy
- Bootstrap

## Setup Instructions

pip install -r requirements.txt

Update PostgreSQL credentials in config.py

Run:
python run.py
